V3 — Glyph Rail

Concept focus: maximum agent visibility at minimum width. Borrows VS Code's activity-bar: a persistent icon rail where every agent is one click, always on screen — no dropdown needed.
  • Icon-only agent rail, each a distinct glyph mark (not letters) to dodge letter-collisions tests U2: glyph vs monogram vs logo-tile
  • Meta-views as icons below a divider — recognition over recall tests U5: icon-only vs labeled
  • Active agent gets the accent indicator bar (one loud element).
  • Hover tooltips + badges carry names/counts so icon-only stays learnable (mitigates the a11y risk of pure icons).
  • Per-pane identity built-in: the panel header repeats the agent's glyph + name.

Best for: users who hop across many agents. Trade-off: glyph legibility must be validated (U2) — the reason V5 trials an alternative mark style.
