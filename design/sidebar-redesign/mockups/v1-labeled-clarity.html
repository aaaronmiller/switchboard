V1 — Labeled Clarity

Concept focus: discoverability-first. Nothing important is icon-only; a first-time user can read every primary affordance.
  • Axis separation: one agent control (Axis A) + a distinct meta-view row (Axis B). They are never mixed — fixing the root cause of the old wrapping dot-row.
  • Labeled meta-views with counts tests U5: labeled vs icon-only
  • Visible “＋ New session” as a Tier-1 action tests U3: visible + vs menu-housed
  • Filter controls hidden, filter STATE shown as removable chips — NN/g rule: defer the control, never the feedback.
  • “+N hidden” line keeps vanished agents explained (Discoverability Critic's non-negotiable).
  • Comfortable density; brand monograms on a fixed 22px grid → perfect alignment.

Best for: new/occasional users, smaller screens. Trade-off: widest vertical footprint of the six.
