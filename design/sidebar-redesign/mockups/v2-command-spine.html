V2 — Command Spine

Concept focus: the all-day power user. Density is comfortable but every action has a key; the chrome is a launchpad, not a wall.
  • Pinned promoted to Tier 1 as a 3-segment control (Active/Flag/Pin) tests U1: Pinned Tier-1 vs Tier-2
  • Comfortable density with cost/token meta on cards tests U4: comfortable vs compact
  • Inline rotate arrows ◀▶ on the agent control + [] — switch agents without opening the menu.
  • Filter controls = icon buttons (sort/time/filter), state shown as a chip. Hidden control, visible state.
  • Keyboard legend always present — teaches the shortcuts that make it fast.

Best for: heavy daily users who triage running + starred work constantly. Trade-off: the 3-segment meta is busier than V1's two buttons.
